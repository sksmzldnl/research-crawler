# ZeroWaste Listening Studio 0.12.0 · Mumsnet·MoneySavingExpert 브라우저 수집

기존 작업실의 검색 대상에 Mumsnet과 MoneySavingExpert를 추가했습니다. Google 사이트 검색으로 쿼리번들을 실행하고 토론 원문 뒤에 댓글을 이어 붙여 토론마다 MD 또는 JSON 파일 하나로 저장합니다. 네이버·Reddit과 두 메뉴 구조를 유지합니다.

- 신규 사이트는 별도 API 키를 입력하지 않습니다.
- 본문 펼치기·댓글 페이지 순회, 반복 원글 중복 제거, 인용문 표시, 댓글 일부/완료 상태를 처리합니다.
- 영국식 일/월/연도와 GMT/BST를 처리하며 날짜만 있는 경우 시각을 만들지 않습니다. 원글 작성일과 댓글 날짜를 구분합니다.
- 설정의 커뮤니티 영역에서 수집 사이트를 골라 브라우저 열기·연결 확인·세션 지우기를 사용합니다. 특정 원문 URL 확인도 두 사이트를 지원합니다.
- 사이트별 앱 전용 프로필을 분리합니다. 필요한 로그인·쿠키 선택·보안 확인은 공식 브라우저 화면에서 직접 진행하고, 정상 페이지로 돌아오면 같은 수집을 이어갑니다.
- 계정 비밀번호·인증코드·다른 브라우저의 쿠키를 읽거나 복사하지 않습니다. CAPTCHA 해결, 접속 차단 우회, 댓글 작성 버튼의 자동 클릭은 없습니다.

- Intel Mac: ZeroWaste-Listening-Studio-0.12.0-mac-x64.dmg
- Windows: ZeroWaste-Listening-Studio-0.12.0-win-x64.exe
- 설치·네이버 키·커뮤니티 수집 안내: Original-Guide-0.12.0-KO.pdf

앱을 종료하고 교체한 뒤 작업실에서 Mumsnet 또는 MoneySavingExpert를 선택합니다. 영어 번들을 편집하고 파일 형식·저장 폴더를 고른 뒤 먼저 글 1개로 실행합니다. 기존 네이버 키와 자료는 유지됩니다. 다른 PC에는 로그인 세션이 전달되지 않습니다.

## 검증 범위와 제한

단위 검사는 포럼 주소·도메인 제한, Google 검색 결과·페이지 이동·중복 제거, 원글과 다중 페이지 댓글 분리, 반복 원글 제거, 인용문·영국 작성일·시차, API 키 없는 서비스 경로와 개별 JSON 저장을 검사합니다. 기존 네이버·Reddit 회귀 검사도 유지합니다.

Electron 실제 창·IPC·폴더 선택·SQLite로 두 사이트의 모의 Google 검색 → 원문 펼치기 → 댓글 3개와 다음 페이지 → MD/JSON 저장을 확인합니다. 쿠키 확인 모의 화면은 앱이 클릭하지 않고 테스트 사용자가 처리한 후 자동 재개되는지, Reply/Log In 버튼은 클릭하지 않는지, 사이트별 세션의 창 재실행·삭제와 API 요청이 없는지 검사합니다. 모든 네트워크 응답은 로컬 fixture입니다.

**현재 개발환경의 목적지 제한 때문에 최신 Mumsnet·MoneySavingExpert·Google 실사이트 화면, robots.txt·약관 및 실제 계정 로그인·수집은 미검증입니다. 오래된 공개 구현과 명시적 화면 구조를 기준으로 구현한 초기 지원입니다. 현 사이트의 수집 허용 범위를 확인해야 하며, 구조가 다르거나 접속이 제한되면 실패·일부 수집으로 표시됩니다. 검색 요약을 원문으로 저장하지 않습니다.**

두 신규 포럼의 한도는 글당 댓글 5,000개·100페이지·읽기 동작 100회·150초, 사용자 확인 대기 최대 10분입니다. Google 색인 전체 확보나 삭제·권한 밖 자료 복구는 보장하지 않습니다. Mac은 ad-hoc 서명이며 Developer ID 공증이 없습니다. ARM64 패키지의 소스·구조·서명은 검사하지만 Apple Silicon 실기기 실행은 미검증입니다.
