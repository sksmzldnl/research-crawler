# ZeroWaste Listening Studio 0.12.8 · Reddit 다음 글 수집

Reddit 글을 읽다가 같은 페이지에서 오래 대기하던 문제를 수정했습니다. 댓글 버튼을 눌러도 내용이 늘지 않거나 댓글 아래 추천 피드가 계속 이어지면 기존 수집기가 종료 시점을 놓칠 수 있었습니다.

- 해당 게시글과 댓글 영역만 읽고 스크롤합니다. 추천 게시글과 그 버튼은 수집 대상으로 삼지 않습니다. 별도의 댓글 스크롤 패널도 처리합니다.
- 추가 본문·댓글이 8초 동안 나타나지 않으면 확보한 내용을 보존하고 다음 글로 넘어갑니다. 댓글이 부족하면 일부 수집·확인 실패와 사유를 파일·목록에 남깁니다. 댓글은 본문 다음에 이어 저장합니다.
- 내용이 늘지 않은 더 보기 버튼을 반복해서 누르지 않습니다. 동일 댓글의 계속 읽기 링크도 주소 변형에 따라 재방문하지 않습니다.
- 본문을 30초 안에 읽지 못한 글은 개별 실패로 기록하고 다음 글을 시도합니다. 로그인·보안 확인 및 창을 닫은 경우에는 기존 사용자 확인·재개 절차를 유지합니다.
- 작업실에서 현재 Reddit 댓글 수집 상태를 볼 수 있습니다. 기존 미니멀 UI와 네이버 블로그·카페·지식인 수집은 유지합니다.

## 검증 범위

응답하지 않는 댓글 버튼, 길게 이어지는 추천 영역, 중첩 스크롤, 늦게 추가되는 댓글, 중복 댓글 링크, 렌더러 무응답, 본문 시간 초과, 수동 확인 대기와 취소를 모의 페이지·시간으로 검증합니다. 네이티브 Electron에서는 첫 글의 댓글이 더 늘지 않아도 본문·확보한 댓글을 MD/JSON으로 저장하고 다음 글까지 자동 수집하는지 확인합니다. 기존 네이버 수집·날짜·댓글·개별 파일 저장·세션 유지 검사도 포함합니다. 실제 Google·Reddit 사이트와 계정으로 재현한 검증은 포함하지 않습니다.

Mac은 ad-hoc 서명이며 Developer ID 공증이 없습니다. Apple Silicon 패키지·소스·서명은 확인하지만 ARM64 실기기 실행은 미검증입니다.
