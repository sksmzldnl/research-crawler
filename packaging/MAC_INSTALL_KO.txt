새로듣기 · Mac 설치 안내
======================

1. 이 ZIP 파일을 Finder에서 더블클릭해 압축을 풉니다.
2. ZeroWasteListener.app을 응용 프로그램(Applications) 폴더로 드래그합니다.
   공유 컴퓨터에서 권한이 없으면 사용자 홈의 Applications 폴더에 복사하세요.
3. 복사한 앱을 더블클릭합니다. Python이나 터미널 명령 설치가 필요하지 않습니다.
4. 먼저 '시연 모드'를 선택해 가상 자료로 화면과 CSV 저장을 확인합니다.
5. 실제 조사는 'API 연결 설정'에서 검색 엔진과 AI의 API 키를 입력한 뒤 실행합니다.

선택할 파일
-----------
- Apple Silicon (M1/M2/M3/M4/M5 등): arm64 버전
- Intel Mac: x86_64 버전
- Apple 메뉴 > 이 Mac에 관하여에서 칩/프로세서를 확인할 수 있습니다.
- 최소 macOS 12.0 이상을 대상으로 합니다.

현재 배포 상태
--------------
이 앱은 Mac용 Python과 Qt 바이너리를 포함한 미서명 테스트 배포본입니다.
Linux에서 패키지 구조, Mach-O 아키텍처, 파일 무결성을 확인했습니다.
실제 Mac에서의 앱 실행·설치와 라이브 API 검증은 아직 완료되지 않았습니다.
Apple Developer ID 서명과 공증은 적용되지 않았습니다.
macOS에서 미확인 개발자 경고가 나타날 수 있습니다. 출처를 확인한 경우에만
Apple의 공식 안내에 따라 시스템 설정 > 개인정보 보호 및 보안에서 판단하세요.
Gatekeeper나 시스템 보안 기능을 끄지 마세요.
공식 안내: https://support.apple.com/ko-kr/102445

제거 / 키 삭제
--------------
앱의 API 연결 설정에서 저장한 키를 삭제한 후 앱을 휴지통으로 옮깁니다.
선택 저장한 키는 macOS 키체인에 보관되므로 앱 삭제만으로 지워지지 않습니다.
실행 로그는 ~/Library/Logs/ZeroWasteListener/app.log에 기록됩니다.
CSV는 저장할 때 선택한 위치에 남습니다.

원문과 API
----------
네이버·다음 블로그와 Reddit의 공식 API를 사용합니다.
Gemini/GPT API 요금은 각 이용자의 계정에 청구될 수 있습니다.
시연 자료는 가상 자료이며 과제의 실제 근거로 사용하면 안 됩니다.
전문 수집이 제한된 자료는 CSV의 '원문 확보 범위'에 이유를 표시합니다.
전체 사용 설명과 라이선스 안내는 앱 내부 Contents/Resources에 포함되어 있습니다.
