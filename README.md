# ZeroWaste Listening Studio 0.8.0

네이버 블로그·카페를 쿼리 번들로 자동 검색하고, **공개 본문 전체를 글마다 별도 MD/JSON 파일로 저장**하는 macOS/Windows 앱입니다. Liquid Glass 디자인과 작업실·설정 두 메뉴를 유지합니다.

[설치 파일](https://github.com/sksmzldnl/research-crawler/releases/tag/studio-api-v0.8.0) · [처음 사용하는 분을 위한 설치·키 발급·수집 안내](docs/ORIGINAL_GUIDE_KO.md) · [배포용 PDF](docs/Original-Guide-0.8.0-KO.pdf)

1. 설정에 NAVER API HUB의 **Client ID / Client Secret**을 각각 등록합니다. 요청 URL은 자동 적용됩니다.
2. 작업실에서 블로그 또는 카페, 쿼리 번들, 목표 수량을 선택합니다. 예: `재사용 AND (불편 OR 후기)`.
3. **파일 형식**에서 MD 또는 JSON을 고르고 **폴더 선택**을 누릅니다.
4. **팝업·배너 광고 제거**를 클릭으로 설정합니다. 광고 영역을 제거하며 협찬 단어가 있는 글 자체를 제외하지 않습니다. 기존 기본 번들의 `NOT 광고`는 제거됩니다. 직접 작성한 제외어·NOT 조건은 유지됩니다.
5. **검색·수집 시작**을 누릅니다. 조건에 맞는 공개 본문을 수집한 글마다 개별 파일로 자동 저장합니다. 성공한 글 10개라면 파일 10개입니다. 실패·조건 제외 자료는 저장 개수에 포함하지 않습니다.
6. 아래 목록에서 전문·게시일·저장 경로·오류를 확인합니다. 다른 형식이나 폴더가 필요하면 **표시된 원문 N개 다시 저장**을 이용합니다.

검색 요약을 전문으로 저장하지 않습니다. API에서 빠진 게시일은 원문 날짜·메타데이터·JSON-LD에서 보완하고, 끝까지 확인되지 않으면 미확인으로 표시합니다. 날짜 필터는 한국 게시일을 유지합니다. 팝업·배너 외의 본문 텍스트는 요약하거나 줄이지 않습니다. 이미지와 첨부는 원문 링크로 보존하며 파일 자체를 내려받지는 않습니다. 댓글·로그인·회원 전용·삭제 글은 수집 범위에 포함되지 않습니다. 정적 HTML에 본문이 없는 공개 페이지는 격리된 데스크톱 렌더러로 로딩합니다. 사이트 구조·접근 제한으로 읽지 못하면 실패로 표시합니다.

AI 요약 화면·모델 설정·API 호출과 CSV 가져오기/AI 내보내기는 제거했습니다. 이전 자료는 앱에서 보존하지만, 이전 검색 요약에 전문이 필요하면 새 수집을 시작해야 합니다. 저장 폴더의 기존 파일은 덮어쓰지 않습니다. 앱에서 기록을 지워도 이미 저장한 파일은 유지됩니다. 앱 재실행 후 수집을 재개할 때는 같은 저장 폴더를 다시 선택하세요.

네이버 키는 가능한 환경에서 OS 암호화로 저장합니다. 다른 PC에는 다시 입력합니다. 보안 저장소를 사용할 수 없는 개발 환경에서는 메모리에만 보관합니다.

## 개발 및 검증

Node.js 24+, Electron 45, React 19, TypeScript, SQLite, jsdom.

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:ui
npm run test:desktop
npm run desktop
```

브라우저 개발 모드에서는 네이티브 폴더 선택을 사용할 수 없습니다. 파일 수집은 설치 앱 또는 `npm run desktop`으로 실행하세요. 선택적 실제 연결 검사는 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `STUDIO_OUTPUT_DIR` 환경변수를 설정한 뒤 `npm run test:live`로 실행합니다. 키와 응답 본문을 출력하지 않습니다.

검증은 공개 HTML 형태의 fixture를 사용한 원문·광고·날짜 추출, 개별 파일 저장, 재개·오류 처리와 Electron 실제 IPC·폴더 선택·SQLite 경로를 포함합니다. 실제 네이버 계정/API 및 현재 서비스의 모든 페이지 구조에 대한 실수집 검증과 M 시리즈 실기기 실행은 수행하지 않았습니다. [릴리스 범위](docs/API_RELEASE.md).
