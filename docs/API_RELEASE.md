# ZeroWaste Listening Studio 0.12.5 · 미니멀 인터페이스

흰색·회색 단색 배경, 얇은 구분선, 기본 체크박스와 텍스트 탭으로 인터페이스를 정리했습니다. 움직이는 배경, 유리·프리즘·물방울 효과, 광학 필터와 관련 설정·코드를 제거했습니다. 큰 그림자, 그라데이션, 화면 전환 애니메이션도 사용하지 않습니다.

네이버 블로그·카페·지식인, Reddit, 쿼리 번들, 연결 확인, 원문·댓글 수집과 개별 MD/JSON 저장은 유지합니다. Mumsnet·MoneySavingExpert는 계속 제외됩니다. 기존 자료·인증정보·선택 값은 유지합니다.

## 검증 범위

화면·설치 앱 검사에서 Canvas·SVG·그라데이션·그림자·필터·애니메이션 부재, 기본 체크박스의 키보드 조작과 저장 값, 두 메뉴 전환을 확인합니다. 검색→원문·댓글→개별 파일 저장은 모의 응답으로 검증합니다. 이번 작업은 실사이트 수집 성공을 새로 검증하지 않습니다.

Mac은 ad-hoc 서명이며 Developer ID 공증이 없습니다. Apple Silicon 패키지·소스·서명은 확인하지만 ARM64 실기기 실행은 미검증입니다.
