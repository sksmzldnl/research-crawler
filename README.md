# ZeroWaste Listening Studio 0.12.2

네이버 블로그·카페·지식인과 Reddit·Mumsnet·MoneySavingExpert를 쿼리 번들로 자동 검색하고, **공개 원문 뒤에 댓글·답글을 이어 붙여 글마다 MD/JSON 파일 하나로 저장**하는 macOS/Windows 앱입니다. 코랄·핑크·보라·옐로 배경은 제한된 크기의 Canvas에서 움직이고, 가장자리는 같은 배경을 넓고 부드럽게 반사합니다. 토글은 전환 중에만 유리 효과를 보이고 평소에는 단순하게 표시합니다. 상시 SVG 배경 굴절과 컨트롤 블러를 제거했습니다. 설정의 화면 영역에서 배경 움직임을 직접 켜고 끌 수 있습니다. 작업실·설정 두 메뉴를 유지합니다.

[설치 파일](https://github.com/sksmzldnl/research-crawler/releases/tag/studio-api-v0.12.2) · [처음 사용하는 분을 위한 설치·키 발급·수집 안내](docs/ORIGINAL_GUIDE_KO.md) · [배포용 PDF](docs/Original-Guide-0.12.2-KO.pdf)

1. 설정에 NAVER API HUB의 **Client ID / Client Secret**을 각각 등록합니다. 요청 URL은 자동 적용됩니다.
2. 작업실에서 블로그·카페·지식인 중 하나, 쿼리 번들, 목표 수량을 선택합니다. 예: `재사용 AND (불편 OR 후기)`.
3. **파일 형식**에서 MD 또는 JSON을 고르고 **폴더 선택**을 누릅니다.
4. **팝업·배너 광고 제거**를 클릭으로 설정합니다. 광고 영역을 제거하며 협찬 단어가 있는 글 자체를 제외하지 않습니다. 기존 기본 번들의 `NOT 광고`는 제거됩니다. 직접 작성한 제외어·NOT 조건은 유지됩니다.
5. **검색·수집 시작**을 누릅니다. 조건에 맞는 공개 본문을 수집한 글마다 개별 파일로 자동 저장합니다. 성공한 글 10개라면 파일 10개입니다. 실패·조건 제외 자료는 저장 개수에 포함하지 않습니다.
6. 설정의 **연결 확인**으로 검색 API·원문·게시일을 각각 확인합니다. **원문 주소 확인**을 펼쳐 특정 URL을 직접 점검할 수 있습니다.
7. 아래 목록에서 전문·게시일·저장 경로·오류를 확인합니다. 다른 형식이나 폴더가 필요하면 **표시된 원문 N개 다시 저장**을 이용합니다.

검색 요약을 전문으로 저장하지 않습니다. API에서 빠진 게시일은 원문 날짜·메타데이터·JSON-LD에서 보완하고, 끝까지 확인되지 않으면 미확인으로 표시합니다. 날짜 필터는 한국 게시일을 유지합니다. 선택한 광고·해시태그 제거 외에 본문·댓글을 요약하지 않습니다. 이미지와 첨부는 원문 링크로 보존하며 파일 자체를 내려받지는 않습니다. 네이버는 공개 글을 읽으며, Reddit의 로그인·확인 화면은 앱 브라우저에서 직접 처리합니다. 삭제 글과 계정 권한으로 볼 수 없는 자료는 수집하지 않습니다. 정적 HTML에 본문이 없는 공개 페이지는 격리된 데스크톱 렌더러로 로딩합니다. 사이트 구조·접근 제한으로 읽지 못하면 실패로 표시합니다.

AI 요약 화면·모델 설정·API 호출과 CSV 가져오기/AI 내보내기는 제거했습니다. 이전 자료는 앱에서 보존하지만, 이전 검색 요약에 전문이 필요하면 새 수집을 시작해야 합니다. 저장 폴더의 기존 파일은 덮어쓰지 않습니다. 앱에서 기록을 지워도 이미 저장한 파일은 유지됩니다. 앱 재실행 후 수집을 재개할 때는 같은 저장 폴더를 다시 선택하세요.

**해시태그 단어 제거**를 켜면 본문의 `#단어` 전체를 제거한 뒤 검색 조건을 적용하고 MD·JSON에 저장합니다. 기본은 꺼짐입니다. 일반 문장·링크 주소·Markdown 제목은 유지하며 선택은 새 수집에 적용됩니다.

**댓글 저장**: 원문 다음에 댓글·답글을 이어 붙이고 글 하나당 MD/JSON 하나를 만듭니다. 추가 로딩과 번호 페이지를 읽으며 중복을 제거합니다. 댓글 수집이 미완료여도 본문을 보존하고 목록·파일에 상태를 표시합니다. JSON은 결합 본문과 구조화된 댓글 목록을 함께 담습니다. **댓글 확인 필요** 필터와 **원문 다시 읽기**를 사용할 수 있습니다.

**커뮤니티 브라우저**: Mumsnet과 MoneySavingExpert도 Google 사이트 검색 → 토론 원문·댓글 페이지 순회 → 개별 MD/JSON으로 연결합니다. 설정의 **커뮤니티 · Google 검색 → 수집 사이트**에서 브라우저 열기·연결 확인·세션 지우기를 관리합니다. 사이트별 세션은 분리됩니다. 영국 포럼의 작성일은 영국식 날짜와 GMT/BST로 해석하고 날짜만 표시된 경우 시각을 만들지 않습니다. **두 신규 사이트는 현재 실사이트 구조·정책·계정 접속 미검증이며, 지원 가능한 공개 화면과 모의 페이지 기준으로 구현했습니다.**

**Reddit**: Google 검색과 Reddit의 일반 브라우저 페이지를 읽습니다. SerpApi 가입·검색 API 키·Reddit API 승인은 필요하지 않습니다. 앱의 **브라우저 열기**에서 필요할 때 직접 로그인하면 이 컴퓨터의 앱 전용 프로필에 유효한 세션을 유지합니다. 로그인·동의·보안 확인이 나타나면 창을 보여 주고 대기하며, 사용자가 정상적으로 완료하면 자동으로 같은 작업을 이어갑니다. CAPTCHA·보안 확인의 자동 해결이나 우회는 하지 않습니다. 브라우저를 닫거나 확인 대기 시간이 끝나면 일시정지하며 수집 재개로 이어갈 수 있습니다. **세션 지우기**는 이 앱의 Google·Reddit 브라우저 프로필에만 적용됩니다. [상세 안내](docs/ORIGINAL_GUIDE_KO.md#8-reddit-브라우저-준비).

카페 본문이 DOM에 없으면 해당 페이지가 정상적으로 요청한 게시글 JSON 응답에서 본문·등록시각을 함께 읽습니다. 다른 글의 응답과 댓글 날짜를 사용하지 않습니다. 프레임·본문·게시일의 지연 로딩을 기다립니다. 상세의 **원문 다시 읽기**로 이전 실패 자료를 다시 읽으며 검색 조건은 그대로 적용됩니다. 지식인은 질문과 페이지에 표시된 공개 답변을 함께 저장합니다.

네이버 키는 가능한 환경에서 OS 암호화로 저장합니다. 다른 PC에는 다시 입력합니다. 보안 저장소를 사용할 수 없는 개발 환경에서는 메모리에만 보관합니다.

## 개발 및 검증

Node.js 24+, Electron 45, React 19, TypeScript, SQLite, jsdom.

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:ui
npm run test:desktop
npm run desktop
```

브라우저 개발 모드에서는 네이티브 폴더 선택을 사용할 수 없습니다. 파일 수집은 설치 앱 또는 `npm run desktop`으로 실행하세요. 선택적 실제 연결 검사는 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `STUDIO_OUTPUT_DIR` 환경변수를 설정한 뒤 `npm run test:live`로 실행합니다. 키와 응답 본문을 출력하지 않습니다.

검증은 공개 HTML 형태의 fixture를 사용한 원문·광고·날짜 추출, 개별 파일 저장, 재개·오류 처리와 Electron 실제 IPC·폴더 선택·SQLite 경로를 포함합니다. 실제 네이버 계정/API 및 현재 서비스의 모든 페이지 구조에 대한 실수집 검증과 M 시리즈 실기기 실행은 수행하지 않았습니다. [릴리스 범위](docs/API_RELEASE.md).
