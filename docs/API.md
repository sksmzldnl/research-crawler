# 네이버 검색과 CSV 인사이트 AI 설정

## 네이버 블로그·카페 검색

1. [NAVER API HUB Application](https://console.ncloud.com/naver-api-hub/application)을 엽니다.
2. 사용할 Application을 선택하고 블로그·카페 검색 상품이 등록되어 있는지 확인합니다.
3. **인증 정보**의 Client ID와 Client Secret을 확인합니다.
4. 앱의 **설정 → 네이버 블로그·카페**에서 Client ID 입력칸에 ID 전체값을 넣고 **등록**을 누릅니다. Client Secret도 해당 칸에 넣고 **등록**합니다.
5. **작업실 → 네이버 검색**에서 블로그 또는 카페를 고르고 번들을 선택한 뒤 **검색·수집 시작**을 누릅니다.

요청 URL·인증 형식은 앱이 자동으로 설정합니다. 콘솔 주소를 복사하거나 요청 주소를 입력할 필요가 없습니다. 키 등록은 저장 상태이며, 실제 인증은 검색 실행에서 확인합니다. 네이버가 상품 이용이나 결제수단 등록을 요구하는 계정은 콘솔에서 해당 조건을 해결해야 합니다.

검색은 공식 검색 요약입니다. 게시글 전문·댓글이 필요하면 직접 확보한 본문 CSV를 가져오세요.

## OpenAI GPT로 CSV 정리

1. [OpenAI API Keys](https://platform.openai.com/api-keys)에서 사용할 프로젝트의 새 API 키를 만듭니다.
2. 생성 직후 표시되는 **Secret Key 전체 문자열**을 복사합니다. 일반적으로 `sk-` 또는 `sk-proj-`로 시작합니다. 마스킹된 `•••` 표시나 일부 글자만 복사하면 인증되지 않습니다. 전체값을 잃었다면 새 키를 발급합니다.
3. 앱의 **설정 → CSV 인사이트 AI → AI 제공자**에서 **OpenAI GPT**를 고릅니다.
4. **OpenAI Secret Key** 칸에 전체값을 붙여넣고 **등록**합니다.
5. 작업실에서 CSV를 가져오거나 수집 결과를 선택하고, 처리할 행을 체크한 뒤 **선택 N행 AI 정리**를 누릅니다.

OpenAI의 **Tracking ID는 관리용 식별자**입니다. API 인증에는 Secret Key 하나를 사용하며 네이버처럼 ID·Secret 두 값을 요구하지 않습니다. OpenAI 로그인 아이디·비밀번호도 사용하지 않습니다. API 키를 채팅에 보내지 마세요.

기본 모델은 `gpt-4.1-mini`입니다. 계정에서 다른 모델을 사용한다면 **AI 모델 설정**에서 구조화된 JSON 응답을 지원하는 모델 이름을 입력하고 **모델 적용**을 누릅니다. 모델 목록을 임의로 조회하는 버튼은 없습니다.

## Gemini로 CSV 정리

[Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 발급하고, 앱에서 **AI 제공자 → Google Gemini**를 선택한 뒤 **Gemini API 키**에 등록합니다. 기본 모델은 `gemini-3.5-flash-lite`입니다. **연결 확인**을 눌러 세 단계를 통과한 뒤 CSV를 처리하세요. 모델 목록 조회만으로는 생성 권한이 확인되지 않습니다. 합성 문장으로 최대 두 번의 실제 생성 요청을 보내므로 프로젝트의 한도·요금이 적용됩니다. 사용할 수 있는 모델·할당량은 계정에서 확인합니다. GPT와 Gemini 키를 모두 등록할 필요는 없습니다.

## 결과와 오류

선택 행의 본문과 분석 관점을 선택한 AI에 전송합니다. 원문과 기존 CSV 열은 유지하고 한국어 요약·인사이트·개선 제안·근거 등을 추가합니다. CSV 가져오기만 할 때에는 외부 전송하지 않습니다.

- **404 (Gemini)**: 요청한 모델을 찾을 수 없습니다. **AI 모델 설정**에서 `gemini-3.5-flash-lite`를 적용하세요. 무료 한도 초과는 보통 429입니다. 현재 모델 별칭은 [Google 공식 SDK 예제](https://github.com/googleapis/python-genai#generate-content)를 참고했습니다. 모델 목록은 무료 과금 여부를 보장하지 않으므로 프로젝트의 등급을 확인하세요.
- **401**: 등록한 키 전체값과 활성 상태를 확인합니다. GPT의 경우 Tracking ID나 가려진 키가 들어가지 않았는지 확인한 뒤 새 Secret Key로 교체합니다.
- **403**: 네이버 상품이나 AI 모델의 이용 권한을 확인합니다.
- **429**: 제공자의 사용 한도·API 잔액·청구 설정을 확인합니다. AI는 남은 행의 호출을 멈춥니다.
- **원문과 일치하지 않는 근거**: 해당 행의 AI 결과를 저장하지 않습니다. 원문을 확인한 뒤 그 행만 다시 선택해 실행할 수 있습니다.
- **응답 시간 초과**: AI 요청은 응답 본문까지 최대 120초를 기다립니다. 그 안에 완료되지 않으면 작업을 멈춥니다. 이미 전송된 요청의 과금 여부를 알 수 없어 자동으로 재호출하지 않습니다.
- **연결 실패**: DNS·TLS 인증서·프록시·연결 거부·연결 끊김을 구분해 표시합니다. 메시지에 해당하는 인터넷·기기 시간·프록시·VPN 설정을 확인합니다. 앱은 시스템 네트워크 설정을 사용하며, 명시적으로 환경 변수 프록시가 설정되어 있으면 그 설정을 유지합니다.

네이버 수집은 **수집 재개**, AI 정리는 오류가 난 행을 다시 선택해 실행합니다. 이미 완료한 행은 그대로 남습니다. 제공자 구독 서비스와 API 과금은 별개이며 앱에서 인증·요금 조건을 우회할 수 없습니다.

## Gemini 연결 확인 (0.7.0)

1. AI Studio에서 만든 Auth 키 또는 Gemini API로 제한된 Standard 키의 전체값을 등록합니다.
2. **연결 확인**을 누릅니다. 키·모델 조회 → 실제 짧은 문장 생성 → 실제 JSON·인사이트 생성 순서로 진행합니다.
3. 모두 통과하면 작업실에서 CSV를 가져와 처리할 행을 선택합니다. 연결 확인에는 CSV 본문을 보내지 않습니다.
4. 실패하면 해당 단계의 HTTP 상태와 키가 가려진 Google 오류 사유를 확인합니다. **진단 내용 복사**로 키·CSV 없이 오류 문구만 복사할 수 있습니다.

키·모델 변경과 앱 재실행 후에는 다시 확인합니다. 연결 성공은 확인 시점의 생성 성공을 뜻하며 무료 이용 자격이나 이후 할당량을 보장하지 않습니다. [프로젝트 상태](https://aistudio.google.com/projects)와 [실제 한도](https://aistudio.google.com/rate-limit)를 확인하세요.

모델 404에서 다른 모델로 자동 전환하지 않습니다. 선택한 모델을 수정하고 다시 확인하세요. 생성 POST는 자동 재전송하지 않으며, 취소는 앱의 응답 대기를 중단합니다. 이미 제공자에 도착한 요청의 취소·과금은 보장하지 않습니다.
