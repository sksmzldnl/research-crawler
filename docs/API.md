# 0.3.0 AI 연결 안내

네이버·Kakao·Reddit 및 검색 API 키는 필요 없습니다. Ncloud 가입·카드 등록도 필요 없습니다. 공개 RSS·URL은 인터넷 연결이 필요하지만 검색 API에 요청하지 않습니다.

## Gemini

1. https://aistudio.google.com/apikey 에 Google 계정으로 로그인합니다.
2. 사용 가능한 프로젝트에서 API 키를 만듭니다. 계정·지역·모델에 따른 무료/유료 제공 조건은 Google 공식 화면에서 확인합니다.
3. 앱의 `AI·수집 설정 → Google Gemini → API 키`에 입력하고 `등록`합니다.
4. `연결 테스트·모델 조회`로 인증과 사용 가능한 모델 목록을 확인합니다.

## OpenAI GPT

1. https://platform.openai.com/api-keys 에 로그인해 프로젝트의 API 키를 만듭니다.
2. 필요한 경우 API 결제 설정을 구성합니다. ChatGPT Plus/Pro 구독은 API 사용료를 포함하지 않습니다.
3. 앱의 `AI·수집 설정 → OpenAI GPT → API 키`에 입력하고 `등록`합니다.
4. `연결 테스트·모델 조회`를 누릅니다.

## 번역·CSV 정리 실행

1. 원문 외부 전송 동의를 선택하고 `설정 저장`을 누릅니다.
2. `데이터 검토`에서 처리할 자료의 체크박스를 선택합니다. 선택하지 않은 행은 전송하지 않습니다.
3. 작업을 `한국어 번역` 또는 `CSV 정리·요약·분류`로 지정합니다.
4. 제공자와 구조화 JSON 출력을 지원하는 모델 이름을 지정합니다. 조회한 목록에서 모델을 선택하거나 정확한 이름을 입력합니다.
5. `선택 N건 AI 처리 실행`을 누릅니다. 번역은 번역 열에, 정리는 요약·경험 분류 등 별도 결과 열에 기록합니다. 원문과 원래 CSV 열은 보존합니다. 재실행하면 해당 결과 열이 갱신됩니다.

키 등록은 인증 성공과 다릅니다. 모델 목록 조회 역시 번역 성공을 의미하지 않습니다. 401은 키/인증, 403은 권한·지역·네트워크, 429는 한도·요금제·요청량을 확인하세요. 실패한 행은 오류를 보존하며 재선택해 실행할 수 있습니다. 완료한 행은 중지해도 보존됩니다.

번역과 정리는 5,000자 단위로 처리하므로 긴 문서의 문맥이 나뉠 수 있습니다. AI 결과는 사람이 검토해야 합니다. 키는 채팅·CSV·소스코드에 붙이지 마세요. 앱의 키 입력란에서만 등록합니다.
