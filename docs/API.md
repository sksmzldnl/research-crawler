# 네이버 연결과 원문 수집

현재 버전의 설정과 사용법은 [설치·키 발급·원문 수집 안내](ORIGINAL_GUIDE_KO.md)를 확인하세요.

0.9.2은 네이버 Client ID와 Client Secret만 사용합니다. 요청 URL은 자동 적용됩니다. 설정의 연결 확인에서 블로그·카페·지식인 검색 API, 원문, 게시일을 따로 점검합니다. 원문 주소 확인으로 특정 URL도 검사할 수 있습니다. 지식인 검색을 쓰려면 Application에 지식iN 권한을 추가하세요.

AI 요약·OpenAI/Gemini 키·CSV 인사이트 기능은 제거했습니다. 이전 AI 관련 조사 문서는 과거 버전의 기록이며 현재 기능 안내가 아닙니다.
