# 구조·보안·구현 범위

## 기술 선택

Tauri와 별도 Python 바이너리 대신 Electron 45의 Node 런타임과 내장 SQLite를 선택했습니다. OS별 Python 번들·프로세스 통신·네이티브 SQLite 모듈 재컴파일 없이 같은 수집 코드를 macOS/Windows에서 실행할 수 있습니다. 설치 크기가 커지는 trade-off가 있습니다. UI는 React/TypeScript이고 수집·키·파일 접근은 main 프로세스에 있습니다.

renderer는 sandbox/contextIsolation을 사용하고 Node 접근을 받지 않습니다. `studio://app` 로컬 프로토콜로 정적 파일만 제공합니다. 원격 HTML을 renderer에 넣지 않습니다. 새 창·원격 이동은 HTTPS 외부 브라우저로만 열며 preload는 한 개의 IPC 호출을 노출합니다. main은 창/frame 출처를 검사하고 service는 Zod로 명령 인자를 검증합니다. 개발 HTTP API는 localhost 바인딩·Origin·커스텀 헤더·JSON 검사를 사용합니다. 웹 개발 모드 키는 메모리만 사용합니다.

## 검색과 상태

논리식은 우선순위 NOT > AND > OR, 괄호, 따옴표 구문, 암묵적 AND를 지원합니다. 안전한 분할 검색을 위해 각 OR 분기에는 최소 하나의 긍정 검색어가 있어야 합니다. 제공자에 긍정 검색어 각각을 요청한 후 전체 AST를 로컬에서 평가합니다. API의 누락/상한을 넘어 완전한 검색을 보장하지 않습니다.

SQLite에는 번들 원본, 조사별 번들·설정 스냅샷, 작업 커서, 자료·오류·사용량을 저장합니다. 페이지 처리 뒤 커서를 저장하며 자료 ID는 조사/번들/소스/제공 ID 기반으로 결정되어 재개 시 이미 저장된 항목을 다시 삽입하지 않습니다. 앱 종료 시 현재 요청을 중단하고 진행 중 조사를 일시정지로 저장합니다. 비정상 종료 후에도 running 상태를 paused로 복원합니다. 완료 페이지의 커서가 캐시 역할을 하며 별도의 장기 HTTP 응답 캐시는 없습니다.

한 검색어당 한 실행에서 최대 10페이지를 처리합니다. Naver 시작 인덱스 상한과 Daum 페이지 상한도 지킵니다. Reddit은 반환된 댓글 트리만 순회하고 `more` 확장·비공개/삭제 댓글은 수집하지 않습니다. 댓글에는 상위 fullname을 저장합니다. RSS는 사용자가 추가한 공개 피드만 읽습니다.

정제는 날짜·논리식·제외어·광고 규칙 이후 URL/게시 ID/본문 해시로 중복을 찾습니다. 선택적 AI 의미 중복 검사는 3-gram 유사도로 후보 5건을 먼저 고른 뒤 선택한 GPT/Gemini 모델이 동일한 경험인지 비교합니다. 양쪽 원문의 실제 인용과 ID를 검증하며, 근거가 맞지 않으면 실패로 남깁니다. 자료당 최대 5,000자, 후보당 최대 5,000자를 전송하므로 별도 비용이 발생할 수 있습니다. 전체 1,000건 쌍을 비교하거나 임베딩을 저장하지 않으므로 모든 의미 중복 검출을 보장하지 않습니다. 중복은 별도 제외 기록으로 보존하면서 대표 자료에 모든 발견 경로를 합칩니다.

## 본문·AI

원문 수집은 HTTPS, 사용자 확인 호스트, 공개 IP DNS 검사, robots.txt, HTML 종류, 2MB 제한, 로그인 필드/저장 금지 메타 확인을 통과해야 합니다. 리디렉션은 자동 추적하지 않습니다. DNS 검사와 실제 프록시 연결의 주소가 달라질 수 있어 이 검사는 네트워크 계층의 DNS rebinding 방어를 대체하지 않습니다. 클라우드는 플랫폼의 egress 정책도 적용됩니다. 외부 문서를 실행하지 않으며 Readability가 텍스트만 추출합니다. 모든 사이트의 약관/유료벽을 자동 판정하지 못하므로 권한 확인은 사용자의 선행 책임입니다.

AI는 필터 통과한 텍스트만 처리합니다. 원문은 청크 전체를 보존하고 번역과 요약을 구분합니다. 스키마와 실제 원문 부분 문자열 인용을 검증하지만, 의미적 환각이나 번역 정확도를 수학적으로 보장하지는 않습니다. 근거·원문과 함께 사람이 검토해야 합니다. AI 처리 실패 자료는 로컬 유효성 판단을 유지하며 AI 실패 상태를 별도 표시합니다. 재시도 시 일부 호출이 이미 과금되었을 수 있습니다.

## 보존과 삭제

작성자 계정을 수집하지 않고 이메일/한국 휴대전화 형식을 마스킹합니다. URL/자유 문장에는 식별정보가 남을 수 있습니다. 보존 기간 삭제는 사용자 버튼으로 실행하며 자동 백그라운드 만료 기능은 없습니다. Reddit 삭제 동기화는 `/api/info`에서 접근 불가/삭제로 확인된 항목을 로컬에서 삭제합니다. 사용자는 공유 전과 보존 중 주기적으로 실행해야 합니다. 자동 정책 준수 인증이나 모든 플랫폼 삭제 웹훅을 제공하지 않습니다.

조사 삭제는 SQLite 외래 키 cascade로 자료를 제거합니다. 전체 삭제는 조사·자료·API 키를 제거하고 쿼리 번들 및 비밀이 아닌 설정은 유지합니다. SQLite 파일·WAL/백업의 저장장치 수준 포렌식 삭제까지 보장하지 않으며 외부로 내보낸 사본은 사용자가 관리합니다.

## 남은 검증·기능 차이

- 실제 네이버/다음/Reddit/OAuth/GPT/Gemini 호출·모델 이용 가능성: 자격증명과 승인 없이 미검증.
- 최신 공식 API 문서/약관 전면 확인: 현재 도메인 정책으로 차단되어 미완료.
- macOS Keychain/Windows DPAPI 및 패키지 설치·서명·공증: 해당 OS에서 미검증.
- Windows는 NSIS EXE만 설정, MSI 없음.
- Google/Bing/Brave 커넥터: 미구현. AI 의미 중복 검사는 후보 5건으로 범위가 제한됩니다.
- RSS/원문 사이트 개별 보존 허가·원문 PII 완전 삭제: 사람 검토 필요.
- AI 광고 판정은 구조화 분석 결과의 의심 표시이며 정답 보장이 아님.

`core/connectors.ts`의 Source별 `search`가 확장 지점입니다. 새 제공자는 타입·설정·키 저장·공식 인증·페이지 종료·날짜 신뢰도·테스트 계약을 함께 추가해야 하며 구현하지 않은 제공자를 성공 상태로 표시해서는 안 됩니다.
