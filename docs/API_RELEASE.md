# ZeroWaste Listening Studio 0.11.0 · API 키 없는 Reddit 브라우저 수집

Reddit 수집에 필요했던 SerpApi·Reddit API 인증정보를 제거했습니다. 기존 작업실에서 Reddit을 선택하면 일반 Google 검색 화면과 Reddit 게시글·댓글 화면을 읽어 원문 뒤에 댓글·답글을 이어 붙이고 MD/JSON 하나로 저장합니다. 네이버 검색 API와 원문·댓글 수집은 유지합니다.

- 별도 API 키·SerpApi 가입·Reddit API 승인이 필요 없습니다.
- 앱 전용 브라우저 프로필에서 유효한 로그인 세션을 재사용합니다. 사이트에서 직접 로그인하며 앱이 사용자 비밀번호를 수집·저장하지 않습니다.
- 로그인·동의·CAPTCHA·보안 확인을 감지하면 화면을 보여 주고 대기합니다. 사용자가 정상적으로 완료하면 같은 작업을 자동으로 이어갑니다. CAPTCHA 자동 해결·보안 우회·식별 위장 기능은 없습니다.
- 브라우저 닫힘·확인 대기 종료는 수집 일시정지로 처리합니다. 검색 위치와 기존 파일을 보존하며 재개할 수 있습니다.
- Google 결과 페이지 순회, 글 ID 중복 제거, 댓글·답글 펼치기와 계속 읽기 링크, 댓글 상태 구분, 기존 해시태그·광고 옵션과 개별 파일 저장을 유지합니다.
- 설정의 브라우저 열기·연결 확인·세션 지우기로 관리합니다. 메뉴는 작업실·설정 두 개입니다.

- Intel Mac: ZeroWaste-Listening-Studio-0.11.0-mac-x64.dmg
- Windows: ZeroWaste-Listening-Studio-0.11.0-win-x64.exe
- 설치·네이버 키·Reddit 브라우저 안내: Original-Guide-0.11.0-KO.pdf

앱을 종료하고 새 버전으로 교체합니다. 기존 네이버 키와 기록은 유지됩니다. Reddit은 작업실에서 바로 선택하고, 필요할 때 앱 브라우저에서 직접 로그인합니다. 파일 저장 폴더는 다시 선택합니다. 기존 자료의 원문 다시 읽기도 새 브라우저 경로를 사용합니다.

## 검증 범위

단위 검사에서 Google 검색 URL·결과·페이지 순회·도메인/커뮤니티 제한·중복 제거, 현대/구형 Reddit HTML 원문·댓글·답글과 게시일, 키 없는 브라우저 경로, 확인/창 닫힘의 일시정지와 재개, MD/JSON 원문·댓글 결합을 검사합니다. 네이버 댓글·게시일·MS949/CP949 회귀 검사도 유지합니다.

Electron의 실제 IPC·SQLite·폴더 선택 경로로 Google 두 페이지 검색→Reddit 원문·댓글/답글 펼치기→MD/JSON을 확인합니다. 보안 확인 모의 페이지는 앱이 클릭하지 않고 명시적인 테스트 사용자 클릭을 기다린 뒤 자동으로 재개되는지 검사합니다. 로그인/Reply 버튼을 클릭하지 않는지, API 요청이 없는지, 합성 세션 쿠키가 브라우저 닫기·앱 전체 재시작 뒤에도 유지되는지와 세션 지우기를 검사합니다. 네트워크는 모두 로컬 페이지/응답 fixture입니다.

현재 클라우드 목적지 제한으로 실제 Google·Reddit 사이트 및 실제 계정 로그인·서비스 차단 해제를 검증한 것은 아닙니다. 사이트가 해당 브라우저를 계속 거부하면 정상 수집을 보장하지 않습니다. Mac/Windows의 패키지 실행 경로를 검사하며 Apple Silicon은 ARM64 파일·패키지 소스·서명 무결성을 검사합니다. Apple Silicon 실기기 실행은 미검증이고 Mac은 ad-hoc 서명·Developer ID 공증 없음입니다.

댓글은 글당 최대 5,000개·브라우저 읽기 120초/동작 100회로 제한하며 확인 대기 시간은 별도로 최대 10분입니다. 한도·미확인·접근 제한은 완료로 숨기지 않습니다. 삭제·권한 밖 자료는 복구하지 않습니다.
